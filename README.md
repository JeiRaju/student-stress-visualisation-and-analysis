# Student Stress Visualisation 📊

This project explores patterns in student mental stress and coping mechanisms using a publicly available survey dataset from Kaggle. By visualising the relationships between academic pressure, sleep habits, support systems, and stress levels, the project aims to uncover meaningful insights into student wellbeing. The analysis focuses on identifying key stress contributors and evaluating the effectiveness of different coping strategies, using visualisation techniques to present findings in a clear, engaging way.

---

## 🔍 Objectives

- Identify academic, lifestyle, and emotional factors contributing to student stress
- Visualise the use and effectiveness of various coping mechanisms
- Explore correlations between stress levels, sleep, GPA, support, and routines
- Present insights in a visually compelling way to inform student support efforts
